# AI-LPR Command Center

ซอฟต์แวร์รู้จำป้ายทะเบียน (LPR) และควบคุมการเข้า-ออก ที่เปลี่ยนกล้อง Hikvision **DS-2CD3146G2-IS** (กล้องทั่วไป ไม่ใช่กล้อง LPR)
ให้ทำงานเป็นกล้องอ่านป้ายทะเบียนไทย พร้อมสั่งไม้กั้นผ่าน Alarm Output ของกล้องโดยตรง — ออกแบบตามแนวคิด HikCentral Entrance & Exit

## เริ่มใช้งาน

1. ดับเบิลคลิก `start.bat` (ครั้งแรกจะติดตั้ง Python packages และดาวน์โหลดโมเดล AI อัตโนมัติ ต้องมีอินเทอร์เน็ต)
2. เปิดเบราว์เซอร์ `http://localhost:8080` หรือจากเครื่องอื่นใน LAN `http://192.168.1.40:8080`
3. เข้าสู่ระบบด้วย `admin / admin1234` แล้ว **เปลี่ยนรหัสผ่านทันที** (เมนูมุมขวาบน)

## หลายกล้อง / หลายช่องทาง

* เพิ่มกล้องที่หน้า **กล้อง & I/O → เพิ่มกล้อง** แต่ละกล้องมีเส้นทริกเกอร์ พื้นที่ตรวจจับ โหมดทริกเกอร์ และการผูก I/O ของตัวเอง
* **ไม้กั้นต่อที่รีเลย์ของกล้องตัวอื่นได้** (เช่น กล้องอ่านป้ายหลังไม่มีสายถึงไม้กั้น) — ตั้งที่ “การผูก I/O ของช่องทางนี้”
* **Loop Detector ที่ต่อเข้ากล้อง A สั่งอ่านป้ายที่กล้อง B ได้** — ตั้งที่ Alarm Input → “สั่งอ่านป้ายที่กล้อง”
* กลุ่มสิทธิ์จำกัดช่องทางได้ (เช่น ผู้มาติดต่อเข้าได้เฉพาะประตูหน้า)
* ทุกเหตุการณ์บันทึกกล้องและทิศทาง (เข้า/ออก) ค้นหา/ส่งออกตามกล้องได้
* AI ใช้ร่วมกันทุกกล้อง: CPU i5 รุ่นปัจจุบันรองรับประมาณ 2-3 กล้องที่ 5-8 fps ต่อกล้อง

## การทริกเกอร์ (ตั้งค่า → การรู้จำ & ทริกเกอร์)

| โหมด | ทำงานอย่างไร |
|---|---|
| **เส้นเสมือน (Virtual line)** — ค่าเริ่มต้น | ระบบติดตามป้ายทะเบียนแต่ละคัน และรายงาน/สั่งไม้กั้นเมื่อป้ายเคลื่อนที่ **ข้ามเส้น** ที่กำหนด เลือกทิศทางได้ (ทั้งสองทาง / ตามลูกศร / สวนลูกศร) |
| วิดีโอต่อเนื่อง | รายงานทันทีที่อ่านป้ายได้มั่นใจ เลือกได้ว่าอ่านเฉพาะรถวิ่งเข้าหากล้อง / ออกจากกล้อง |
| Loop Detector | เริ่มอ่านเมื่อ Alarm Input ที่กำหนดบทบาท Loop Detector ทำงาน |
| เส้น + Loop (Mixed) | รายงานเมื่อข้ามเส้น **หรือ** Loop ทำงาน แล้วแต่อย่างใดเกิดก่อน (แบบ Mixed trigger ของกล้อง ANPR) |

วาดเส้นและ **พื้นที่ตรวจจับแบบหลายเหลี่ยม** ได้ที่ **ตั้งค่า → เส้นทริกเกอร์ & พื้นที่ตรวจจับ** (เลือกกล้องได้):
ลากจุด A/B วางเส้น · ลากมุมสีเหลืองปรับพื้นที่ · ลากจุดกลางขอบเพื่อเพิ่มมุม · ดับเบิลคลิกมุมเพื่อลบ · ปุ่ม “ครอบรอบเส้น” สร้างพื้นที่ช่องจราจรให้อัตโนมัติ

ความแม่นยำ: รถแต่ละคันถูกอ่านหลายครั้งระหว่างวิ่งเข้ามา แล้ว **รวมความน่าจะเป็นของทุกเฟรม** (CTC) ร่วมกับกฎรูปแบบป้ายไทย และรายชื่อทะเบียนในระบบ
ก่อนตัดสินผล (ช่วยตัวที่ OCR สับสนบ่อย เช่น ห/ท, ธ/ร) ทำให้รถหนึ่งคันได้ผลลัพธ์เดียวที่เสถียร

## AI Training — สอน AI ด้วยข้อมูลหน้างาน

1. ทุกครั้งที่ **แก้ไขทะเบียนที่อ่านผิด** (หน้าค้นหาเหตุการณ์) ภาพป้ายจะถูกเก็บเป็นตัวอย่างอัตโนมัติ
2. หน้า **AI Training → ตรวจสอบผลอ่าน** แสดงผลอ่านที่ความมั่นใจต่ำก่อน — พิมพ์ทะเบียนที่ถูกแล้วกด Enter (หรือ “ข้าม” ถ้าภาพไม่ชัด)
3. เมื่อมีตัวอย่าง ≥ 20 ภาพ (แนะนำ 100-300) กด **เริ่มเทรน** — ทำงานเบื้องหลังบน CPU ประมาณ 5-20 นาที ระบบอ่านป้ายยังทำงานตามปกติ
4. ระบบแบ่ง 20% ไว้ทดสอบ วัดความแม่นยำเทียบโมเดลเดิม และ **เปิดใช้เฉพาะเมื่อแม่นกว่า** — ย้อนกลับไปโมเดล Base ได้ทุกเมื่อ
5. แท็บภาพรวมแสดงตัวอักษรที่อ่านผิดบ่อย (เช่น ท → ห) และตัวอักษรที่ยังมีตัวอย่างน้อย

ภาพในชุดข้อมูลเก็บที่ `data/dataset/` และโมเดลที่เทรนแล้วที่ `data/models/ft/` (ไม่ถูกลบตามระยะเวลาเก็บข้อมูล)

## Alarm I/O ของ DS-2CD3146G2-IS

> **สำคัญ:** หากในกล้องตั้ง Linkage ให้ Motion Detection / Tamper / Defocus สั่ง Alarm Output ไว้ กล้องจะสั่งรีเลย์เองทุกครั้งที่มีการเคลื่อนไหว
> ทำให้ไม้กั้นเปิดเองและคำสั่งจากซอฟต์แวร์ถูกกลบ — หน้า **อุปกรณ์ & I/O → ความพร้อมของ Alarm I/O** จะตรวจพบและมีปุ่มยกเลิก Linkage ให้ในคลิกเดียว
>
> Alarm Input รับเหตุการณ์ผ่าน Event Stream ของกล้อง (ตอบสนองทันที) และอ่านสถานะแบบวนรอบเป็นช่องทางสำรอง

กล้องตัวนี้ (FW V5.7.55) รายงานผ่าน ISAPI ว่ามี **Alarm Output 1 ช่อง และ Alarm Input 1 ช่อง**
ซอฟต์แวร์อ่านจำนวนพอร์ตจากกล้องโดยอัตโนมัติ หากใช้กล้องที่มีหลายช่องจะแสดงให้เลือกเองทั้งหมด

* **Alarm Output → ไม้กั้น**: ต่อ `ALARM OUT` / `COM` เข้ากับขา `OPEN` / `COM` ของชุดควบคุมไม้กั้น
  กำหนดบทบาท “ไม้กั้น” ที่หน้าอุปกรณ์ (หรือ “ไซเรน” สำหรับแจ้งเตือนบัญชีดำ)
* **Alarm Input** (เผื่อติดตั้งภายหลัง) — เลือกบทบาทได้ที่หน้าอุปกรณ์:
  * **Loop Detector** — เมื่อมีรถทับลูป ระบบจะเริ่มอ่านป้าย (ตั้งโหมดทริกเกอร์เป็น “Loop Detector” ในหน้าตั้งค่า)
  * **Radar / Anti-fall** — ขณะมีวัตถุใต้ไม้กั้น ระบบจะค้างสัญญาณเปิดไม้กั้นไว้ไม่ให้ไม้ตีรถ

## การดึงภาพผ่าน HCNetSDK

ค่าเริ่มต้นของกล้อง Hikvision คือดึงภาพด้วย **HCNetSDK** (พอร์ต 8000, `app/hik_capture.py`) แล้ว decode ด้วย PlayCtrl
ภาพทั้งหมด (ภาพสด, snapshot, ภาพหลักฐาน, ปุ่มทดสอบ) มาจาก HCNetSDK อย่างเดียว — ไม่ใช้ RTSP และไม่ดึงภาพผ่าน HTTP
ถ้าไม่พบ DLL สถานะกล้องจะแสดง “ไม่พบ HCNetSDK ใน hiksdk/” (ไม่มีการสลับไปใช้ RTSP)
ช่อง “แหล่งวิดีโอทดแทน” ใช้ได้เฉพาะไฟล์วิดีโอในเครื่องสำหรับทดสอบ

* วาง SDK x64 ไว้ที่ `hiksdk/lib` หรือ `hiksdk/include` (ต้องมี `HCNetSDK.dll`, `PlayCtrl.dll` และโฟลเดอร์ `HCNetSDKCom`)
  หรือกำหนดตำแหน่งเองด้วย environment variable `HIKSDK_DIR`
* Python ใน `.venv` ต้องเป็น 64-bit · log ของ SDK อยู่ที่ `data/logs/hiksdk/`
* Alarm I/O, Event stream และการตั้งค่าภาพยังใช้ ISAPI (HTTP พอร์ต 80) เหมือนเดิม

### ภาพสดแบบ ClientDemo (หน้าต่างเดสก์ท็อป)

`start_desktop.bat [--cams 1,2]` เปิดหน้าต่าง 2 ช่อง + เซิร์ฟเวอร์เว็บในโปรเซสเดียวกัน (ใช้แทน `start.bat`)
PlayCtrl วาดภาพลงหน้าต่างเองผ่าน `PlayM4_Play(port, hwnd)` ส่วน LPR ดึงเฟรมล่าสุดจาก decode callback ไปประมวลผลใน thread ของตัวเอง
ภาพสดจึงลื่นเท่าความเร็วกล้องไม่ว่า LPR จะช้าแค่ไหน · console พิมพ์ `[FPS] decode … | LPR …` ทุก 5 วินาที

## เคล็ดลับความแม่นยำ (สำคัญมาก)

กล้องรุ่นนี้ไม่ใช่กล้อง LPR โดยกำเนิด ความแม่นยำขึ้นกับการติดตั้งเป็นหลัก:

* ติดตั้งให้ป้ายในภาพกว้าง **≥ 130 พิกเซล** (Main stream 2688×1520) มุมเงยไม่เกิน 30° มุมเอียงไม่เกิน 20°
* **Shutter สำคัญที่สุด** — ค่าโรงงาน 1/25 s ทำให้รถที่เคลื่อนที่เบลอ ใช้ปุ่ม “โหมดไม้กั้น · 1/250” ที่หน้า **กล้อง & I/O → ปรับภาพสำหรับอ่านป้าย**
  (ตั้ง Shutter 1/250, WDR, HLC กดไฟหน้ารถ, DNR 35, ความคม 60 และเก็บค่าเดิมไว้ให้กดคืนค่าได้) Focus ตรงตำแหน่งรถผ่านเส้น
* กลางคืนใช้ IR ของกล้อง เปิด HLC หลีกเลี่ยงแสงไฟหน้ารถส่องตรง
* ใช้ “พื้นที่ตรวจจับ” ครอบเฉพาะช่องทางรถ เพื่อลดการอ่านผิดและเพิ่มความเร็ว
* ใช้ “ศูนย์ทดสอบ → อัปโหลดรูป” ทดสอบภาพจริงจากหน้างานก่อนเปิดใช้
